# Liquidity incentives

Revert has an [incentives section](https://revert.finance/#/incentives) that displays the currently running incentives programs on the Uniswap v3 canonical staker contract, as well as the time-vested staker contract.<br>

![](<../.gitbook/assets/image (27).png>)

Uniswap v3 position dashboards automatically detect and display the rewards accrued by each position.

![](<../.gitbook/assets/image (77).png>)

We also detect and display any incentives program available for the position and pair, even if the position is not currently staked and accruing rewards.

\
You can manage the staking, unstaking, and claiming of any rewards  directly from your position dashboard.
