# Playbooks

The feature pages tell you what each tool does. Playbooks tell you when to reach for which, and how the tools combine into something none of them does alone. Each one walks a decision: the setup, the numbers that drive it, and the conditions under which you should do the opposite.

- [Compound or collect](compound-or-collect.md): when reinvesting fees beats taking the income, by chain and position size.
- [Backtest before funding](backtest-before-funding.md): choosing a range with evidence instead of instinct.
- [The staked-collateral carry](carry-on-staked-aerodrome.md): running a borrow against a staked Aerodrome position, and the triggers for unwinding it.

The examples use round illustrative numbers. Live rates, gas costs, and emissions move; the decision structure is the part that holds.
