# Uniswap v4 Positions

![Uniswap v4 position example](../.gitbook/assets/v3position.png)

{% hint style="info" %}
Uniswap V4 is currently in early stages. Analytics and Position Management features are available on Ethereum mainnet and Unichain.
{% endhint %}

## Supported Networks

- Ethereum mainnet
- Unichain

## Position Metrics

Uniswap v4 uses the same analytics metrics as Uniswap v3. All metrics are calculated identically to provide consistency across protocol versions.

For detailed definitions of all position metrics including:
- Pooled assets
- APR and fee APR
- Pool PnL and Total PnL (vs HOLD, vs ETH, vs USD)
- Current assets, invested assets, and withdrawn amounts
- Unclaimed and claimed rewards

Please see the [Uniswap v3 Positions](uniswap-v3-positions.md) documentation.

## Pool Definitions

Pool-level metrics also match Uniswap v3 definitions:
- Reserves
- Volume
- Price divergence
- Position age

For complete pool definition explanations, refer to the [Uniswap v3 Positions](uniswap-v3-positions.md) page.
